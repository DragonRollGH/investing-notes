## 怎么用这份笔记

- 按顺序读。1-3 章是地基，跳过会看不懂后面的策略

- 第 7 章是完整的实战案例，把前六章的数字串一遍

## 三条贯穿全文的原则

1. **期权是零和的**。你赚的钱来自对手方，不是公司成长。所以期权不是"更好的股票"，是"另一种赌法"
2. **买方付保险费，卖方收保险费**。保险一定有人买（怕崩盘），也一定有人卖（想要现金流）。两边都能赚钱，但死法不同
3. **任何策略的收益率都写在它的风险结构里**。看到"3 倍收益"就要去找"3 倍亏损在哪"，找不到就是没看懂
